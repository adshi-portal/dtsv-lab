3. Перелік виявлених суперечностей і помилок

Правило пріоритету: РПНД → МВ до практичних робіт → конспект лекцій → ТЗ. Математично помилкові числа в МВ не відтворюються в тренажерах: система рахує правильно, а розбіжність показує в режимі «Навчання» з приміткою.

3.3. Розбіжності ТЗ і МВ за обсягом

ТЗ розширює ПР2–ПР9 (графіки ризику, логарифмічна правдоподібність, навчальна вибірка й пороги в ПР4, конструктор логічних схем і таблиці істинності в ПР5, F1/Specificity у ПР8, послідовні та паралельні системи в ПР9). Ці функції реалізуються як додаткові дослідницькі блоки, явно позначені «поза МВ», а ядро кожного тренажера точно відтворює методику МВ. Найбільший розрив — ПР4: у МВ метод зводиться до максимуму апостеріорної ймовірності (без навчальної вибірки й порогів). Пропозиція: ядро за МВ, а модельний блок оцінює P(kⱼ/Dᵢ) за частотами навчальної вибірки (формули (3)–(4) ПР1) і будує матрицю помилок.

4. Математична специфікація ПР1 (реалізована)

Дано: n ∈ {3, 4} діагнозів D₁…Dₙ, ΣP(Dᵢ) = 1, P(Dᵢ) ∈ (0, 1); m ∈ {2, 3} двоградаційних ознак, P(kⱼ/Dᵢ) ∈ [0, 1]; реалізація K* = (k₁*, …, kₘ*), kⱼ* ∈ {kⱼ, ¬kⱼ}; поріг розпізнавання Pₗ.

Алгоритм (МВ ф-ли 10, 12, 14, 15, 18–20):

  1. Робоча таблиця: P(kⱼ*/Dᵢ) = P(kⱼ/Dᵢ), якщо ознака виявлена, інакше 1 − P(kⱼ/Dᵢ).
  2. P(K*/Dᵢ) = Πⱼ P(kⱼ*/Dᵢ) — (10).
  3. P(DᵢK*) = P(Dᵢ)·P(K*/Dᵢ) — (14).
  4. P(K*) = Σₛ P(DₛK*) — (11).
  5. P(Dᵢ/K*) = P(DᵢK*)/P(K*) — (15); контроль ΣP(Dᵢ/K*) = 1 — (13).
  6. Діагноз: i* = arg max P(Dᵢ/K*) — (18); якщо P(Dᵢ*/K*) ≥ Pₗ — діагноз прийнято (19), інакше відмова від розпізнавання (20).

Коректність вхідних даних: |ΣP(Dᵢ) − 1| ≤ 10⁻⁹; усі ймовірності в [0, 1]; P(K*) > 0 (інакше реалізація неможлива за даної матриці — повідомлення, без ділення на нуль).

Допуск перевірки відповідей: |x − x_ref| ≤ max(0,0015; 0,01·|x_ref|) — приймається округлення до 3 знаків; десятковий роздільник — кома або крапка.

Генерація варіантів: ідентифікатор PR1-<хеш(група|ПІБ|номер)>. Генератор mulberry32 із сідом від хешу FNV-1a; ймовірності кратні 0,05; відкидаються варіанти з P(K*) = 0 або різницею двох найбільших апостеріорних < 0,03. Варіант № 0 — приклад МВ (с. 8) без змін.

Контрольні приклади (автотести): МВ с. 8–9: K* = k₁k₂ → (0,0909; 0,9091; 0); ¬k₁k₂ → (0,1237; 0,4639; 0,4124); ¬k₁¬k₂ → (0,0336; 0,0540; 0,9124).

Розподіл балів ПР1 (100 % = повне виконання): вихідні дані (робоча таблиця) — 15; вибір формул — 10; точність розрахунків — 35; інтерпретація (найімовірніший стан) — 10; технічне рішення (поріг, рекомендація) — 10; контрольні запитання — 20. Підказка знімає 25 % ваги кроку; повторна спроба після помилки — 50 % ваги. Рівень: ≥ 90 % — A (IV), 82–89 — B, 75–81 — C (III), 64–74 — D, 60–63 — E (II), < 60 — FX/F (I), за шкалою РПНД.

  • ПР5: правила — кон'юнкції атомарних умов (>, ≥, <, ≤, =, ∈[a, b]), Y = OR(правил), інакше «не визначено»/0. Контроль — дані МВ с. 16 з виправленими висновками (П4, П5). Конструктор: блоки AND/OR/NOT, таблиця істинності, дерево рішень.
  • ПР6: A = k·P₂; x₀ = Φ⁻¹(1 − A; μ₁, σ₁); β = Φ((x₀ − μ₂)/σ₂). Контроль: (0,15; 6,555; 0,0425). Φ⁻¹ — алгоритм Acklam/Wichura з точністю 10⁻⁹, тест на табличних значеннях.
  • ПР7: x̄, s² (n−1), z-оцінки, 3σ, Pearson r, гістограма (k інтервалів), H = −Σ pᵢ log₂ pᵢ, H_max = log₂ k, оцінка диференційної ентропії h ≈ H + log₂ Δ. Контроль: виправлені числа МВ (П10).
  • ПР8: TP/FP/TN/FN → Accuracy, Precision, Recall, Specificity, F1, FAR = FP/(FP+TN), MDR = FN/(FN+TP); ділення на нуль → «не визначено». Контроль: МВ с. 25–26 → 0,7; 0,8; 0,667.
  • ПР9: T̂ = Σtᵢ/n; λ̂ = 1/T̂; P(t) = e^(−λt); емпірична P*(t) = 1 − F_n(t); CV; гістограма; послідовне P = ΠPᵢ, паралельне P = 1 − Π(1 − Pᵢ) (конспект, ф-ли 5.29–5.34). Контроль: T̂ = 7, λ̂ = 0,1429, P(5) = 0,4895.
