# Інтерактивна лабораторія діагностики технологічних систем

Тренажери практичних робіт з дисципліни «Діагностика технологічних систем і виробництв» (ВНТУ, кафедра технологій та автоматизації машинобудування, проф. С. В. Ковалевський).

**Версія 0.2 (етап 5, партія 1):** реалізовано тренажери ПР № 1–4 у всіх п'яти режимах:

- ПР1 — метод Байєса;
- ПР2 — мінімальний ризик;
- ПР3 — максимальна правдоподібність;
- ПР4 — мінімальна кількість помилкових рішень.

ПР № 5–9 — наступна партія. Рішення щодо відкритих питань зафіксовано в `docs/01-analiz-specyfikatsiia.md`, розд. 7.

## Запуск

Система статична, збирати її не потрібно.

```bash
npx http-server . -p 8080      # або: python3 -m http.server 8080
# відкрити http://localhost:8080
```

Відкрити `index.html` подвійним кліком не вийде: браузери блокують ES-модулі для `file://`, тому потрібен локальний сервер.

## Публікація на GitHub Pages

1. Створіть репозиторій і завантажте вміст цієї папки в корінь гілки `main`.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `(root)`.
3. Сайт буде доступний за адресою `https://<користувач>.github.io/<репозиторій>/`.

Файл `.nojekyll` вимикає обробку Jekyll. Маршрутизація через `#pr1-step`, `#formulas` працює на GitHub Pages без додаткових налаштувань.

## Тести

```bash
node --test tests/*.test.mjs     # Node.js ≥ 18, без залежностей
```

34 автотести перевіряють:

- контрольні приклади методичних вказівок ПР1–ПР4;
- граничні випадки: P(K*) = 0, детермінувальна ознака, поріг рівний апостеріорній;
- некоректні дані;
- формули (3)–(5) і (16)–(17);
- відтворюваність і коректність 2000 згенерованих варіантів;
- розбір чисел і допуски;
- систему оцінювання.

## Технологічні рішення

Під час розробки встановлення npm-пакетів було недоступне, тому стек ТЗ замінено рівноцінним без залежностей (обґрунтування — `docs/01-analiz-specyfikatsiia.md`, розд. 6):

| Компонент ТЗ | Замінено на |
|---|---|
| React | нативні ES-модулі |
| Plotly | власні SVG-графіки |
| KaTeX | MathML |
| jsPDF | друк браузера → «Зберегти як PDF» (коректна кирилиця) |

Перехід на React/Vite можливий без змін у `src/calculations`.

## Обмеження прототипу

- Результати зберігаються лише в браузері студента (localStorage); централізованого журналу немає. Для здачі використовується PDF-звіт із кодом цілісності.
- Код цілісності виявляє ручне редагування звіту, але не є криптографічним захистом: справжній захист потребує серверної частини.
